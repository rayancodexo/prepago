PREPAFLOW — VERSION LOCALE

Windows : double-cliquez sur start-prepaflow.bat.
Le site s'ouvrira sur http://localhost:8080

Alternative sans serveur : ouvrez dist/index.html directement.
Les matières, tâches, événements, sessions et XP sont enregistrés dans votre navigateur.

MISE À JOUR : remplacez les fichiers de l'ancienne installation par ceux-ci,
sans effacer les données du navigateur. Utilisez le même navigateur et la même
adresse (http://localhost:8080) pour retrouver votre progression.
La version en ligne et la version locale conservent des données séparées.

Calendrier : cliquez sur un jour pour planifier, modifier ou supprimer un créneau.
Concentration : durées d'étude et de pause réglables, matière et objectif quotidien.
Le total du jour inclut la session en cours et exclut les pauses.
Le minuteur continue jusqu'à la fin prévue si vous fermez l'onglet : mettez-le
en pause quand vous arrêtez d'étudier. Terminer enregistre le temps déjà étudié.

ANNALES CNC
- Choisissez MP, PSI, ECS ou EST, puis la matière et l'une des 10 dernières années.
- Ajoutez le lien du sujet lorsque vous l'avez. Le lecteur, le chrono de 4 h,
  les notes et la note sur 20 restent enregistrés sur cet appareil.
- Marquer une épreuve comme terminée rapporte 150 XP.

MES MATIÈRES
Chaque chapitre comporte cinq étapes : cours, résumé, exercices faciles,
exercices avancés, puis validation finale. Un chapitre complet rapporte 100 XP.
La page affiche d'abord toutes les matières. Cliquez sur une matière pour ajouter,
suivre ou supprimer ses chapitres. Supprimer un chapitre retire son XP des totaux.
